# ProjectMatch - University Allocation System

ProjectMatch is a Django-based web application designed to automate and streamline the process of matching university students to final year projects offered by supervisors.

## Features Included
- **Centralized Authentication:** A single login page intelligently routes Students, Supervisors, and Admins to their respective dashboards.
- **Drag-and-Drop Preferences:** Students rank their project choices using a seamless, interactive UI.
- **Automated Allocation Algorithm:** A fair mathematical engine processes all student rankings and strictly enforces project quotas.
- **Suitability Checker:** Supervisors can instantly see what percentage of prerequisites an applicant meets based on their modules/skills.
- **Real-time Notifications:** A live navbar bell alerts users of new actions (e.g., allocation updates, preference reminders).
- **Responsive 3D Interface:** Built using Bootstrap 5 with custom CSS to provide a tactical, push-button aesthetic.

## How to Run The Project Locally

This project uses `pipenv` to manage Python dependencies.

### Prerequisites
1. Ensure you have Python installed.
2. Ensure you have [Pipenv](https://pipenv.pypa.io/en/latest/) installed (`pip install pipenv`).

### Setup Instructions

1. **Clone the repository and open the folder in your terminal.**
2. **Install all dependencies** by running:
   ```bash
   pipenv install
   ```
3. **Activate the virtual environment:**
   ```bash
   pipenv shell
   ```
4. **Apply database migrations:**
   ```bash
   python manage.py migrate
   ```
5. **(Optional but Recommended) Seed the database.**
   This command clears the current database and sets up a fresh batch of Students, Supervisors, Admins, and Projects. It's the best way to get instant test data.
   ```bash
   python manage.py seed_final_data
   ```
   *Note: Read `test_accounts.txt` for the passwords generated by this script.*

6. **Start the development server:**
   ```bash
   python manage.py runserver
   ```
7. **Open the browser:** Navigate to `http://127.0.0.1:8000/` and you should see the central login page!
